## 🎯 행정학과 학생부종합전형(학종) 핵심 연계 포인트

대학 입학사정관과 행정학과 교수님들이 가장 주목하는 **4대 행정학 핵심 역량**이 프로그램에 그대로 녹아 있습니다:

1. **정책 과정론 (Policy Process)**
   - 단순한 민원 제기가 아닌 **[사회 문제 정의 ➔ 정책 목표 설정 ➔ 대안 탐색 ➔ 집행 주체 선정]**의 체계적인 접근
2. **비용편익분석 (Cost-Benefit Analysis, B/C 분석)**
   - 재정학과 정책분석론의 기초인 예산 대비 사회적 편익(사고 예방비용, 주민 편익 등)을 수치화하여 타당성(B/C $\ge$ 1.0) 도출
3. **뉴거버넌스론 및 갈등 관리 (Stakeholder Management)**
   - 관료 중심의 일방적 행정이 아니라 주민, 경찰, 교육청, 민간 기업이 협력하는 거버넌스 네트워크 및 주민 수용성 시뮬레이션
4. **생기부 제출용 고품질 보고서 원클릭 출력 (Print to PDF)**
   - A4 서식의 행정 보고서가 실시간 생성되며, 브라우저 인쇄 기능으로 세특/수행평가 제출용 PDF를 즉시 생성 가능
